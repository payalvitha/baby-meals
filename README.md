# 🍼 Baby Meals — PWA

Your personal Solid Starts-style baby food app with food tracking, recipes, meal planner & grocery list.

---

## 🚀 Deploy in ~10 Minutes (Free, No Coding Required)

### Step 1 — Create a GitHub account
Go to [github.com](https://github.com) and sign up (free).

### Step 2 — Create a new repository
1. Click the **+** icon → **New repository**
2. Name it `baby-meals`
3. Set it to **Public**
4. Click **Create repository**

### Step 3 — Upload files
1. Click **uploading an existing file** link on the repo page
2. Upload ALL the files from this folder, keeping the folder structure:
   ```
   index.html
   vite.config.js
   package.json
   public/favicon.svg
   src/main.jsx
   src/App.jsx
   src/index.css
   src/hooks/useStorage.js
   src/data/foods.js
   src/data/recipes.js
   src/components/FoodLibrary.jsx
   src/components/Recipes.jsx
   src/components/MealPlanner.jsx
   src/components/Profile.jsx
   ```
3. Click **Commit changes**

### Step 4 — Deploy with Vercel
1. Go to [vercel.com](https://vercel.com) and sign up with your GitHub account
2. Click **Add New Project**
3. Select your `baby-meals` repository
4. Vercel auto-detects Vite — just click **Deploy**
5. Wait ~60 seconds — your app is live! ✅

You'll get a URL like `baby-meals.vercel.app`

### Step 5 — Add to iPhone Home Screen
1. Open the URL in **Safari** (must be Safari for PWA install)
2. Tap the **Share** button (box with arrow)
3. Tap **Add to Home Screen**
4. Tap **Add**

That's it! It now works like a real app — offline too. 📱

---

## ✨ Features
- **Food Library** — 35+ foods with allergen info, texture guides, reaction logging with notes
- **Recipes** — Purées, Indian baby food (khichdi, dal, ragi), and BLW finger foods
- **Meal Planner** — Weekly grid, pick recipes for each day
- **Grocery List** — Auto-generates from your meal plan, tap to check off
- **Baby Profile** — Name, age, allergies, food log history
- **100% local** — All data stays on your device, no accounts needed
